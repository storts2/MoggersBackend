# Milton Moggers - Backend
This is the backend for my milton moggers website. For more information visit the frontend repository here: https://github.com/storts2/MoggersFrontend

## Features
- REST API
- Endpoints for team stats
- Endpoints for player stats
- Endpoints for match stats
- CORS configuration

## Technologies
- Java
- Spring Boot
- Swagger UI
- PostgreSQL
- Gradle
- Spring Web
- Spring Data JPA

## Getting Started
### Prerequisites
- IntelliJ IDEA 2025+
- Java
- PostgreSQL database with required schema

### Installation
- Clone repository https://github.com/storts2/MoggersBackend.git
- Configure application.properties file to connect to your DB
- Configure CORS to allow requests from the frontend
- Run the program

## Usage
### Project Structure
- Config - CORS config is here
- Controllers - All endpoints are here
- DTO - Classes for data transfer objects are here
- Entity - Classes for entities are here
- Repository - Database repositories are here
- Service - Services for controllers are here
### Documentation
API documentation is available through Swagger UI: http://localhost:8080/swagger-ui/index.html
